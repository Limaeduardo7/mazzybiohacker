# /atualizar

## Objetivo

Atualizar regras duráveis sem transformar o GitHub em um dump de CRM.

## Workflow

1. Mapear pastas, skills e arquivos recentes.
2. Ler os quatro arquivos em `_memoria/`, `CLAUDE.md` e `identidade/design-guide.md`.
3. Identificar mudanças duráveis:
   - novo posicionamento
   - nova regra comercial
   - novo processo recorrente
   - nova taxonomia de produto
   - nova regra documental
   - nova skill
4. Não copiar estados transitórios de leads ou quotes para a memória pública.
5. Propor alterações em lista curta.
6. Aplicar somente após aprovação do usuário.
7. Mostrar diff conceitual do que mudou.

## Regra

Se a informação pertence à operação viva, atualize a fonte operacional canônica, não a memória pública.
