# /rfq-fornecedor

## Workflow

1. Confirmar demanda:
   - product
   - process / grade
   - target volume
   - destination
   - packaging
   - required certifications
   - timing
2. Separar must-have de nice-to-have.
3. Escrever RFQ curta e clara.
4. Pedir, quando aplicável:
   - price tiers
   - MOQ
   - Incoterm
   - lead time
   - origin
   - packaging
   - sample availability
   - TDS / COA
   - certification evidence
5. Registrar respostas na fonte operacional correta.

## Regra

Não enviar target price do cliente automaticamente. Só usar quando houver decisão comercial explícita para ancorar a negociação.
