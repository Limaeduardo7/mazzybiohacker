# Biohacker Weekly Content

## Objetivo

Produzir conteúdo internacional consistente com o posicionamento de ingredient house / supply partner.

## Antes de gerar

Ler:
- `_memoria/empresa.md`
- `_memoria/estrategia.md`
- `_memoria/preferencias.md`
- `identidade/design-guide.md`
- `marketing/README.md`

## Mix semanal sugerido

Distribuir temas entre:
- ingredient education
- application / formulation
- sourcing / origin
- quality / documents
- product spotlight
- B2B capability
- brand / commercial CTA

## Regras editoriais

- Inglês como padrão.
- Não fazer claims médicos.
- Não inventar ORAC, certificações, origem, estoque ou propriedades funcionais.
- Explicar processo quando relevante: freeze-dried ≠ spray-dried ≠ fried/dehydrated.
- CTA B2B.
- Evitar posts genéricos de wellness.

## Formato

Planejamento semanal em `planejamento/semana-AAAA-MM-DD.json`.

Cada item:
- slug
- date
- category
- theme
- hook
- caption
- CTA
- slides

Carrossel: 5–8 slides, pouco texto e hierarquia visual forte.

## Publicação

Quando scripts de Buffer estiverem configurados:
1. validar
2. renderizar
3. conferir assets
4. agendar
5. registrar IDs retornados
6. arquivar no GitHub

Nunca afirmar que um post foi agendado sem ID real da plataforma.
