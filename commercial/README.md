# Commercial

## Objetivo

Transformar interesse em oportunidade qualificada e avançar cada conta para um próximo passo verificável.

## Fluxo padrão

1. Identificar empresa e contexto.
2. Qualificar produto, volume, destino, documentação e timing.
3. Verificar se existe supply adequado.
4. Definir próximo passo: informação, amostra, cotação, reunião ou follow-up.
5. Registrar o estado na fonte operacional canônica.

## Estados conceituais

- NEW
- QUALIFYING
- SUPPLIER_MATCH
- SAMPLE
- QUOTING
- NEGOTIATION
- WAITING_EXTERNAL
- WAITING_APPROVAL
- WON
- LOST

Os nomes reais dos estados podem ser diferentes no sistema operacional. A fonte viva sempre prevalece.

## Follow-up

Follow-up deve acrescentar valor ou remover um bloqueio. Evitar “just checking in” sem contexto.

## Mensagens

Toda mensagem deve responder a três perguntas:
- por que estamos falando com esta empresa?
- qual valor / informação estamos trazendo?
- qual próximo passo queremos?
