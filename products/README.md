# Products

## Taxonomia principal

- Freeze-dried powders
- Spray-dried powders
- Frozen pulps / purees
- Concentrates
- Whole / pieces where commercially relevant
- Superfood ingredients

## Campos técnicos recomendados

Para cada produto, capturar quando aplicável:
- botanical / common name
- process
- origin
- ingredients
- carrier / additives
- moisture
- mesh / particle size
- microbiology
- color / sensory
- Brix for pulp / puree
- organic status
- allergen statement
- shelf life
- storage
- packaging
- application notes

## Comparação

Não comparar dois produtos apenas pelo nome. Process, concentration, additives, certifications and specification can change the commercial value materially.
