# Documents

## Standard document set

Quando aplicável, buscar:
- TDS / Product Specification
- COA
- Organic certificate
- Kosher
- Halal
- HACCP / FSSC / BRC or equivalent food-safety evidence
- Certificate of Origin
- Health / sanitary certificate when required
- Allergen statement
- Shelf-life / storage information

## Regras

- Nunca afirmar certificação sem evidência válida.
- Verificar nome legal, produto coberto, validade e escopo.
- COA de lote não substitui TDS.
- Certificado de empresa não prova automaticamente certificação do SKU.
- Para negociação internacional, mapear documentação ao destino e aplicação do cliente.
